# electronic-ecom-backend
Electronic ecom frontend is the repository of a backend code of international electronics e-Commers company. code written in dotnet tech-stack
1. Create github accounts and repositry
2. Install postgresql for windows
3. install dotnet-ef globally(entity framework tool for commands)
4. postgres Admin user - postgres, password - Root@1234, Port - 5432
5. postgres Admin db - ecommerce_db, db user - ecommerce_db_user, db password - Ecommerce@db@user@password
6. Add Entity Framework Core(dotnet add package Microsoft.EntityFrameworkCore.Design)
7. Add PostgreSQL package (dotnet add package Npgsql.EntityFrameworkCore.PostgreSQL)
8. Create Tables Products, Regions, Sales Transactions and Users
9. Create Scaffold of DB and Models
10. Added DTOs
11. Added services
12. Added Autoampper by using (dotnet add package 
AutoMapper.Extensions.Microsoft.DependencyInjection)
13. Add NuGet package Npgsql.EntityFrameworkCore.PostgreSQL
14. Add package for password hasher dotnet add package Microsoft.AspNetCore.Identity
15. Installing JWT by running dotnet add package Microsoft.AspNetCore.Authentication.JwtBearer
